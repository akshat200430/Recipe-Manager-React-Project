# Recipe-Manager-React-Project
Recipe Manager is a frontend-only web application built with React and Tailwind CSS. It allows users to create, view, edit, delete, and save recipes as favourites. All data is stored in the browser using LocalStorage, making it simple, fast, and ideal for practicing React hooks, routing, and CRUD functionality.

🍽️ Recipe Manager

Recipe Manager is a frontend-only web application built using React.js and Tailwind CSS.
It allows users to create, manage, and save recipes using browser LocalStorage, without any backend or authentication.

This project was built to practice core React concepts and simulate real-world CRUD functionality on the frontend.

✨ Features

📝 Create recipes with title, chef name, description, instructions, and category

👀 View all recipes on a dedicated Recipes page

✏️ Edit and update existing recipes

🗑️ Delete recipes

❤️ Add and remove recipes from favourites

⭐ View favourite recipes on a separate page

💾 Data persistence using browser LocalStorage

📱 Responsive and modern UI with Tailwind CSS

🛠 Tech Stack

React.js

React Router DOM

Tailwind CSS

Browser LocalStorage

Frontend-only Architecture

📂 Pages in the Application

Home – Introduction and overview of the app

Recipes – Displays all created recipes

Create Recipe – Form to add a new recipe

Recipe Details – View, edit, delete, and favourite a recipe

Favourite – Displays all favourite recipes

About – Information about the project and developer

🎯 Purpose of the Project

This project was created to strengthen understanding of:

React component-based architecture

React Hooks (useState, useEffect, useContext)

Client-side routing with React Router

State management and data persistence

Building a complete frontend workflow without a backend

🚀 Getting Started
1️⃣ Clone the repository
git clone https://github.com/akshat200430/Recipe-Manager-React-Project.git

2️⃣ Navigate to the project folder
cd recipe-manager

3️⃣ Install dependencies
npm install

4️⃣ Run the development server
npm run dev


The app will start on http://localhost:5173 (Vite default).
